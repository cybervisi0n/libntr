# Contributing to libntr
Thank you for your interest in contributing to the libntr project! Please read these guidelines before making contributions or submitting pull requests.

1. We do not accept AI generated contributions at this time.
2. libntr is a **game-agnostic** reimplementation of the NitroSDK. It is meant to work with all DS games, not just one. For example, if you want to add a custom shader specifically for pokeplatinum, that change definitely belongs in pokeplatinum and not here. However, an interface to load/use custom shaders would belong here and consuming projects could then use it.
3. PRs must pass CI
